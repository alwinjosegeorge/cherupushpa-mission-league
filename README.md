# Cherupushpa Library Hub

Design a modern minimalist Christian library website for Cherupushpa Mission League.

The website should feel like a premium mobile application translated into a website experience.

Design Inspiration:

• Modern grocery apps

• Premium SaaS interfaces

• Minimal e-commerce websites

• Mobile-first UI

• Apple-inspired spacing

• Clean dashboard aesthetics

Design Style:

• Modern Minimal Library UI

• Card-based layout

• Soft UI elements

• Subtle neumorphic touches

• Rounded corners

• Soft shadows

• Spacious layouts

• Elegant typography

• Smooth animations

• Premium yet simple

• Calm and welcoming atmosphere
